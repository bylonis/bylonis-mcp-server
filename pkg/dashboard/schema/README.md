# ClickHouse schema

`logs.txt`, `metrics.txt` and `traces.txt` are generated by `tools/genschema` from the migrations of
`bylonis-otel-collector`; do not edit them by hand. The server embeds them and serves them as MCP
resources.

Regenerate after a collector release that changes the schema (CI fails while they are stale):

```sh
cd tools/genschema && go get github.com/bylonis/bylonis-otel-collector@<tag> && go mod tidy
go run . ../../pkg/dashboard/schema
```
